# Veebileht informaatikatudengile

Rühm Lehva veebileht aitab Tartu Ülikooli mineval informaatikatudengil vajalikku infot leida.

## Lehe ülesehitus

- **Avaleht** – tähtsad kuupäevad, üritused ja KKK.
- **Kes ja kus?** – kontaktid, õppehooned
- **Kõik teemad** – ainetele registreerumine, õppekeskkonnad


Rühmatöö plaanis kokku lepitud käitumisnormid on meile endiselt olulised, meie arvates ei ole vaja midagi lisada ega muuta.
